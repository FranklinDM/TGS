# The Good 'ol Sidebar (TGS)

A sidebar control extension for [Pale Moon](https://www.palemoon.org) and [Basilisk](https://basilisk-browser.org).

TGS is a fork of the discontinued [All-in-One Sidebar (AiOS)](http://firefox.exxile.net/aios/index.php) for Mozilla Firefox, bringing classic Opera-style sidebar functionality back to modern XUL-based browsers.

Download the latest release from the [Pale Moon Add-ons site](https://addons.palemoon.org/addon/tgsidebar/) or check the [Wiki](https://github.com/FranklinDM/TGS/wiki) for documentation.

## Features

- **Panel quick-switching:** Open downloads, add-ons, bookmarks, page source, and custom webpages directly inside the sidebar.
- **Edge toggle and slide-out:** Click the browser edge or use the slide-out toggle button to reveal or collapse panels instantly.
- **Configurable layout:** Dock the sidebar to the left or right edge, set custom width constraints (minimum, default, maximum), and choose startup behavior.
- **Extensive customization:** Fine-tune appearance, animations, toolbar placement, and built-in shortcut behaviors via the options dialog.
